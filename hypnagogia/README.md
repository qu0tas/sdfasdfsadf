# Гипнагогия (Hypnagogia)

Двухмерный roguelike-шутер с видом строго сверху о снах, памяти и забвении. Игрок управляет Крошкой Нолём — последним стражем, который очищает ветви Древа Снов.

Игра работает в браузере: HTML, CSS, JavaScript (ES-модули) и Three.js, который используется только как 2D-рендер (ортографическая камера, плоские спрайты, фильтрация «ближайший сосед»). Сервер, аккаунты и интернет для игры не нужны.

## Как запустить

Нужен [Node.js](https://nodejs.org/) версии 20 или новее. Все команды выполняются в корне репозитория (на уровень выше этой папки).

```sh
npm install      # один раз: скачивает зависимости
npm run dev      # запускает игру для разработки
```

После `npm run dev` откройте в браузере `http://localhost:5173/`. Вторая игра репозитория, Hollow Sun, доступна по адресу `/hollow-sun/`.

```sh
npm test         # проверяет данные и логику (предметы, сердца, генерацию этажей)
npm run build    # собирает готовый сайт в папку dist/
npm run art      # заново рисует все листы спрайтов в assets/sheets/
```

Собранный сайт лежит в `dist/` и работает на любом статическом хостинге. Гипнагогия — его главная страница.

## Управление

| Клавиша | Действие |
| --- | --- |
| W A S D | движение |
| Мышь, левая кнопка | прицел и стрельба |
| Стрелки | стрельба в четыре стороны |
| Пробел или Shift | рывок с короткой неуязвимостью |
| E | поставить чернила (ломают преграды, вскрывают тайники) |
| Q | активный предмет |
| F | взаимодействие (колодец, зеркало) |
| Tab или M | карта |
| Esc или P | пауза |

Геймпад: левый стик — движение, правый — стрельба, A — рывок, X — чернила, Y — предмет.

Крошка Ноль нарисован по концепт-арту автора; его цвета и пропорции заданы в `tools/art/char-zero.mjs`.

## Что есть в игре

- **Забег из трёх этапов:** Корни Древа, Детская, Сердце домена. Каждый этап — заново собранная сетка комнат, соединённых разломами в четырёх стенах.
- **Комнаты:** бои, элитные бои, сокровищница, лавка, головоломка, событие (колодец или зеркало), спрятанная комната, мини-босс, босс, стёртая дверь.
- **Выбор пути:** значок у разлома показывает, что за ним; дрожащий разлом скрывает это. После босса открываются два разлома дальше: один называет сон, в который ведёт, другой — нет.
- **Восемь видов врагов** с разным поведением, мини-босс и три босса: Ком Забытого, Малый Страж «Заводной», Сердце Детских Игрушек.
- **28 предметов и 7 синергий.** Предметы меняют числа, добавляют теги и уникальное поведение; выстрелы превращаются в ноты, зубы, пузыри и плюшевых мишек.
- **Ресурсы:** Сонная пыль (валюта), Осколки (ключи), Чернила (бомбы). **Сердца:** красные, синие и стеклянные.
- **Головоломка сна:** порядок знаков нарисован мелом в разных комнатах этапа; его нужно заметить и запомнить, игра его не записывает. Код стёртой двери один на всё сохранение и собирается по частям за несколько забегов.
- **Постоянный прогресс:** коллекция предметов, бестиарий, отметки, открывающие новые предметы, статистика. Прерванный забег можно продолжить.
- **Настройки:** громкость (общая, музыка, звуки), тряска экрана, сброс прогресса.

## Что решено за автора и ждёт подтверждения

Бриф оставляет эти вопросы открытыми. Чтобы игра была цельной, в ней приняты рабочие варианты. Это предложения, а не канон.

- **Порядок этапов** и состав боссов. Ком Забытого как босс Корней придуман для этой версии.
- **Правила сердец.** Урон снимает сначала синие сердца, потом полное стеклянное, потом красные. Полное стеклянное сердце поглощает один удар любой силы и снова пустеет. Его наполняет эссенция побеждённых врагов: 12 единиц на сердце.
- **Конец забега.** Смерть возвращает к корням без памяти о прошлом. После Сердца Крошка Ноль стирает ветвь вместе с собой, и забег начинается заново.
- **Забвение** только упоминается в финальном тексте. Его облика и боя с ним в игре нет.
- **Цены, шансы и сила предметов** — первые прикидки, а не выверенный баланс.

## Чего пока нет

- Переназначения клавиш в меню. Раскладка меняется в одном месте: `src/input/Input.js`, таблица `BINDINGS`.
- Комнат с персонажами, кроме торговца.
- Пути Забвения, новых доменов, нескольких концовок.

## Как устроен код

```
index.html              страница игры (лежит в корне репозитория)
hypnagogia/
  styles.css            интерфейс: меню и HUD
  assets/sheets/        листы спрайтов (PNG) и описания их анимаций (JSON)
  tools/art/            скрипты, которые рисуют листы спрайтов
  tests/                проверки данных и логики
  src/
    main.js             точка входа: проверка данных, загрузка графики, запуск
    app/                Game (экраны и события забега), игровой цикл, загрузка графики, размеры
    rendering/          Three.js: рендер, анимированные спрайты, фон комнаты, эффекты
    input/              клавиатура, мышь, геймпад
    audio/              звуки и музыка (синтезируются в браузере)
    save/               сохранение в localStorage
    data/               предметы, теги, синергии, враги, этапы, комнаты, отметки, баланс
    gameplay/
      player/           Крошка Ноль
      enemies/, bosses/ существа и их поведение
      combat/           снаряды и столкновения
      health/           три вида сердец
      items/            сборка характеристик и уникальное поведение предметов
      rooms/            генерация этапа, наполнение комнат, живая комната, разломы, находки
      puzzles/          плиты со знаками
      progression/      состояние забега
    ui/                 HUD, карта, меню
    utils/              случайные числа с зерном, математика
```

### Как добавить предмет

1. Допишите запись в `src/data/items.js`: идентификатор, название, описание, теги и эффект.
2. Нарисуйте значок с тем же идентификатором в `tools/art/world-items.mjs` и выполните `npm run art`.
3. Выполните `npm test`: проверка сообщит, если в записи ошибка.

Числовые эффекты задаются в `mods`, изменения выстрела — в `shot`. Уникальное поведение пишется в `src/gameplay/items/behaviours.js`, а его идентификатор добавляется в `behaviourIds.js`. Синергии описаны в `src/data/synergies.js`.

### Отладка

Адрес с `?debug` кладёт объект игры в `window.hypnagogia`. Зерно забега пишется в консоль браузера: с ним этажи повторяются точно.
